시간이 지나거나 횟수를 넘기면 강퇴됩니다. 다음 실행부터 적용됩니다.

서버 프로그램 (Bedrock Dedicated Server)

플레이어의 마인크래프트가 업데이트되면 서버도 같은 버전이어야 접속할 수 있습니다. 새 버전은 서버를 다음에 실행할 때 적용되고, 월드는 그대로 유지됩니다.

Java 서버 프로그램 (Java Edition)

Java 서버는 서버마다 게임 버전을 고릅니다. 고른 버전의 서버 프로그램과, 그 버전에 맞는 Java 실행 환경을 Mojang 공식 서버에서 받아 data/java에 둡니다 (처음 실행할 때 자동으로 받으므로 미리 받지 않아도 됩니다). 플레이어는 런처에서 서버와 같은 버전을 골라 접속합니다.
